OrangeHRM Automation Project. Este proyecto tiene como objetivo automatizar tareas clave en la plataforma de demostracion de OrangeHRM (https://opensource-demo.orangehrmlive.com/) utilizando Playwright como framework de automatizacion y TypeScript para la robustez del codigo. Las caracteristicas principales incluyen: uso de Tecnologia Moderna con Playwright para una automatizacion rapida y confiable en multiples navegadores, implementacion de Lenguaje Tipado con TypeScript para mejorar la calidad y mantenibilidad del codigo, la aplicacion del Page Object Model (POM) para una estructura clara y escalable, y la ejecucion de Pruebas End-to-End (E2E) para cubrir flujos criticos de la aplicacion. Para comenzar, los prerrequisitos son tener instalado Node.js (Version 16.x o superior) y npm. La instalacion se realiza en tres pasos: clonar el repositorio (git clone [TU_URL_DEL_REPOSITORIO] y cd orangehrm-playwright-ts), instalar las dependencias (npm install) e instalar los browsers de Playwright (npx playwright install). La ejecucion de todas las pruebas se realiza con npx playwright test. Para ejecutar solo en un navegador especifico, se usa npx playwright test --project=chromium. Para ejecutar una suite de pruebas especifica, usa npx playwright test tests/login.spec.ts. Puedes usar el modo debug visual con npx playwright test --ui. La estructura del proyecto se organiza con el Page Object Model e incluye los siguientes directorios y archivos clave: tests/ (para archivos de prueba como login.spec.ts), pages/ (para las Clases POM como LoginPage.ts y BasePage.ts), data/ (para datos de prueba como testdata.json), playwright.config.ts (archivo de configuracion principal) y package.json (dependencias y scripts). El archivo playwright.config.ts define el baseURL como https://opensource-demo.orangehrmlive.com/, un timeout de 60000 ms, 1 reintento para pruebas fallidas y la ejecucion en proyectos como chromium, firefox y webkit.
